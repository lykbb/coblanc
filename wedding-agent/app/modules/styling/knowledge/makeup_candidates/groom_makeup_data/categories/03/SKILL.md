# 韩式柔和妆

原文件夹标签保留作检索入口，不推定四图同人同妆，也不把分类名称强加给每张图。具体可见特征以案例为准。

- [MMAKEUP000044 · 自然毛流眉与柔粉裸唇](../../cases/MMAKEUP000044/SKILL.md)：眼周颜色淡，上眼缘有轻深色轮廓；浅粉唇较柔雾，边缘自然。 来源未核实。
- [MMAKEUP000045 · 柔棕眼缘与自然玫粉润唇](../../cases/MMAKEUP000045/SKILL.md)：上眼缘深色较细，眼窝柔棕层次；玫粉唇偏柔润，唇中较深。 来源未核实。
- [MMAKEUP000046 · 柔棕眼周与低饱和玫棕唇](../../cases/MMAKEUP000046/SKILL.md)：眼周偏粉棕，下眼缘也可见浅色层次；低饱和玫棕唇，偏柔润。 来源未核实。
- [MMAKEUP000047 · 浓眉对比与珊瑚红润唇](../../cases/MMAKEUP000047/SKILL.md)：下眼周浅暖棕，眼缘较深；唇色珊瑚红偏润，色彩较明显。 来源未核实。
