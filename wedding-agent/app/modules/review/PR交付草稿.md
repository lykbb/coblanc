# PR 标题

[review] 完善质检返工、真实模型入口及离线评测诊断

# PR 描述草稿

原 review 仅有示例分数与固定返工方向，真实质检和修图决策是占位。此修改保留 fake 模式和既有节点契约，完善质量拦截与返工方向校验，并实现真实视觉及返工模型调用入口、双人特征配对、离线评测／标定／基线对比、独立诊断及批量报告。

例如一位人脸分数不达标时不能用另一位高分掩盖，也不能接受 agent 返回“换婚纱”；已有合格候选可以换用，用户明确重做时按现有 reason 处理。返工后保留原照片与回答，最终交付用户确认的候选。

所有修改位于 wedding-agent/app/modules/review/，check(state)、retouch(state) 的普通 def 和允许返回字段不变，未修改公共骨架、配置、依赖或其他模块。报告与人工标注字段属于离线工具，不写入 WeddingState。

验证：review 197 项、契约 24 项、全量 267 项通过。mock 批量、单张诊断、六接口流程、自动返工、并发隔离、连续返工上限和合成基线对比均验证。运行方法见 README 与本目录交付说明。

真实边界：视觉／返工分支使用模型替身测试，未调用付费服务；照片到人脸特征的供应商入口仍未实现，完整真实 check 暂不能运行。真人照片、效果阈值、供应商费用和性能未验收。部分候选失败仍沿用整轮失败，待框架统一政策。

成功例子：模拟双人图通过六接口走到交付；批量两组合成工单执行成功，实际模型调用为 0，其中一组 hands 重做生成 generate 方案。

失败例子：低人脸分数下 agent 错选 look、漏返候选、选择历史图片、服务未配置或授权缺失均明确失败；报告不泄露图片、URL、密钥或原始供应商错误。

待协调：人脸服务选型、必要的公共依赖／配置、获准服务与预算、授权回归集和部分失败政策。
