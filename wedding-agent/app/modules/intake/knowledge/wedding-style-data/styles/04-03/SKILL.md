# 04-03 · 深林静谧童话

分类名是检索入口，不是强制风格模板。先比较场景、服装轮廓、光影与互动，选一组为主参考；跨组组合需检查兼容性。未经跨案例验证的共同点不得升级为必选项。客户方案确认后保持组内一致，跨客户可以更换变量。

- [SET000004 阿里山静谧森林](../../cases/SET000004/SKILL.md)：密集树干、幽暗林间轨道及苔绿环境；白色轻纱长裙与长头纱，新郎灰蓝西装，部分白伞；低饱和棕绿，横向环境构图与选择性虚焦
- [SET000023 迷雾森林骑士](../../cases/SET000023/SKILL.md)：深绿林间路径、雾气与树冠明暗层次；白色抹胸亮面蓬裙和长头纱、黑西式礼服，黑马与白马；静谧对称骑乘、前后站位和长裙拖尾，偏戏剧化
