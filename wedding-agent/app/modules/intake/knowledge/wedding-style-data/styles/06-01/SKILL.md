# 06-01 · 极简缎面高定

分类名是检索入口，不是强制风格模板。先比较场景、服装轮廓、光影与互动，选一组为主参考；跨组组合需检查兼容性。未经跨案例验证的共同点不得升级为必选项。客户方案确认后保持组内一致，跨客户可以更换变量。

- [SET000003 灰底光影缎面主纱](../../cases/SET000003/SKILL.md)：灰色棚景、圆形亮区和清晰投影、白色缎面蓬裙；俏皮姿态与亲密近景结合。
- [SET000024 月亮湖缎面主纱](../../cases/SET000024/SKILL.md)：蓝天、山林、青绿色湖面与草地，另有树荫下的场景；白色缎面观感细肩带蓬裙与头纱，黑色礼服，垂坠白绿花束；明亮日光、绿白黑对比，环境留白与近景互动并用
- [SET000028 南法鱼尾白纱](../../cases/SET000028/SKILL.md)：米黄色拱门、黑框高窗、吊灯与花艺餐桌、编织座椅；象牙白贴身长裙，部分蕾丝手套与花朵发饰，新郎浅色黑驳领礼服；柔和暖色室内，门洞框景与窗边自然光观感
- [SET000036 黑背景缎面主纱](../../cases/SET000036/SKILL.md)：纯黑棚景背景，人物与白裙轮廓突出；白色抹胸大蓬裙，银色花卉装饰，卷发侧饰，黑色三件式礼服；柔和面部照明，明亮裙面，兼有俏皮互动与亲密肖像
- [SET000042 复古缎面主纱](../../cases/SET000042/SKILL.md)：橄榄棕色纹理棚景、压暗四周，侧向明暗层次；露肩长袖交叠领白色缎面蓬裙，低盘发，新郎黑礼服；白兰花及白绿垂坠花束，静态庄重肖像
- [SET000048 粉调蕾丝缎面主纱](../../cases/SET000048/SKILL.md)：粉色纹理棚景，粉绿垂坠花束；白色缎面大裙摆，部分蕾丝肩颈罩层、泡袖、头纱分镜变体，新郎黑礼服；柔和明亮光感，仪式肖像与比心等轻松动作交替
- [SET000050 低腰线缎面主纱](../../cases/SET000050/SKILL.md)：室内床铺、白床品与棕色横条木墙；白色抹胸收腰蓬裙，新郎黑礼服；亲密轻松床边互动，俯视斜线与正面造型并用
- [SET000075 DSJ黑背景缎面主纱](../../cases/SET000075/SKILL.md)：纯黑棚景背景，人物与白裙轮廓突出；白色抹胸大蓬裙，银色花卉装饰，卷发侧饰，黑色三件式礼服；柔和面部照明，明亮裙面，兼有俏皮互动与亲密肖像【同画面版本，不独立计证据】
