# 01-01 · 洱海清透轻旅拍

分类名是检索入口，不是强制风格模板。先比较场景、服装轮廓、光影与互动，选一组为主参考；跨组组合需检查兼容性。未经跨案例验证的共同点不得升级为必选项。客户方案确认后保持组内一致，跨客户可以更换变量。

- [SET000018 紫色花神洱海清透](../../cases/SET000018/SKILL.md)：闪光湖面、深色碎石岸与远山，蓝紫冷调；灰紫色抹胸多层蓬纱及花饰，新郎深色外套白裤，粉色花束；逆光水面光斑，软化与运动模糊观感，拥抱和贴近肖像
- [SET000019 蓝色花神洱海清透](../../cases/SET000019/SKILL.md)：阳光湖岸沙地、闪光蓝色水面与远山；蓝色抹胸花饰层叠大蓬裙和长拖尾，蓝花头饰与头纱，新郎灰色西装；明亮蓝调、大裙摆占幅，牵手走动、依偎与坐姿
