# 06-12 · 高定杂志封面

分类名是检索入口，不是强制风格模板。先比较场景、服装轮廓、光影与互动，选一组为主参考；跨组组合需检查兼容性。未经跨案例验证的共同点不得升级为必选项。客户方案确认后保持组内一致，跨客户可以更换变量。

- [SET000027 灰调缎面高定](../../cases/SET000027/SKILL.md)：中灰纯棚景与定向柔和明暗；白色抹胸缎面观感蓬裙与蕾丝边装饰、长直发，新郎黑礼服；白兰花和低情绪幅度的时尚肖像
- [SET000045 灰调水波纹主纱](../../cases/SET000045/SKILL.md)：灰色棚景配流动水波状亮纹；白色长袖闪饰上身与缎面大蓬裙、冠饰，新郎黑礼服；显著高光曲线、托脸和坐姿肖像，部分活泼手势
- [SET000060 玫瑰漫境室内主纱](../../cases/SET000060/SKILL.md)：灰褐色墙板室内、浅色木地板与复古长沙发；白色简洁抹胸上身与密集立体花朵大裙摆、长头纱，新郎黑礼服；白花瓣漫撒与窗侧光束观感，裙摆占大面积
- [SET000073 纱花帽高定主纱](../../cases/SET000073/SKILL.md)：灰色纹理棚景，低饱和粉白色调；前6帧浅粉立体花裙、大纱花头饰与黑礼服；后3帧白色花裙、宽檐花帽及白礼服；庄重站坐肖像与大裙摆轮廓，组内存在明确造型分段
- [SET000076 薇阁室内拖尾主纱](../../cases/SET000076/SKILL.md)：米色古典墙板、门框、壁灯及深色装饰物；白色抹胸缎面蓬裙、蕾丝边长头纱，新郎黑礼服；暖暗室内与窗侧光，宽大拖尾、前景虚化和亲密肖像
