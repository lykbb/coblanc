# 02-01 · 传统红金喜嫁

分类名是检索入口，不是强制风格模板。先比较场景、服装轮廓、光影与互动，选一组为主参考；跨组组合需检查兼容性。未经跨案例验证的共同点不得升级为必选项。客户方案确认后保持组内一致，跨客户可以更换变量。

- [SET000016 红金庭院国风大婚](../../cases/SET000016/SKILL.md)：中式木门庭院、台阶红毯、红灯笼与囍字迎亲装饰；新娘红金装饰长裙与披袖拖尾，新郎黑色带金色纹样中式礼服；红金黑主色，彩纸和挥手、抛物形成喜庆动感
- [SET000030 红金华服凤冠](../../cases/SET000030/SKILL.md)：园林白墙黛瓦、木廊及绿树，门洞框景；新娘红金贴身露肩礼裙与金色长披帛、大型流苏头冠，新郎黑色金纹立领服；金色配饰细节和庄重相依姿态，红金与冷绿环境对照
- [SET000037 红鎏拖尾秀禾](../../cases/SET000037/SKILL.md)：深色中式建筑、灯笼长廊、山水装饰墙与玻璃窗；红金露肩修身长裙及极长红色披帛拖尾，新郎黑色立领长服；大面积红布与建筑透视线条，庄重对望及撑伞
- [SET000064 重工红金拖尾秀禾](../../cases/SET000064/SKILL.md)：红色帷幕与大字背景、暖米色局部墙地；红金露肩贴身礼裙、金色长披帛和流苏头冠；新郎酒红金纹上衣配浅金长下摆；庄重正面肖像与掀盖头、整理配饰互动
- [SET000071 红金秀禾囍字椅](../../cases/SET000071/SKILL.md)：红色棚景、金黄珠帘囍字、木椅与花艺灯笼；新娘红色花卉装饰立领上衣配长裙，新郎黑色立领盘扣服；明亮喜庆氛围，掀帘、标语道具与坐姿玩笑
