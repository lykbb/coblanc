# 03-01 · 奶油暖调柔光

分类名是检索入口，不是强制风格模板。先比较场景、服装轮廓、光影与互动，选一组为主参考；跨组组合需检查兼容性。未经跨案例验证的共同点不得升级为必选项。客户方案确认后保持组内一致，跨客户可以更换变量。

- [SET000025 奶油暖调韩式主纱](../../cases/SET000025/SKILL.md)：奶油米色纯净棚景、均匀柔亮观感；白色露肩闪饰蓬裙、大型纱花帽与头纱，新郎全白礼服；粉玫瑰点缀，站坐相依、比心与戒盒主题
- [SET000066 粉调蕾丝缎面主纱](../../cases/SET000066/SKILL.md)：粉色纹理棚景，粉绿垂坠花束；白色缎面大裙摆，部分蕾丝肩颈罩层、泡袖、头纱分镜变体，新郎黑礼服；柔和明亮光感，仪式肖像与比心等轻松动作交替【同画面版本，不独立计证据】
